## 💻 Local Development

```bash
# 1. Clone the repository
git clone https://github.com/Suryaprasath-41/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. Build for production
npm run build
```
